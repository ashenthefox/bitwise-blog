PASS if, before it lists what is in the figure, the answer states the point the figure makes: a claim the reader should come away with, in one to three sentences, set apart as the point (for example under "The point"). A second sentence that restates or completes the first still counts.
FAIL if no statement of the point comes before the contents, or if what is given is a topic ("a figure about LZ77 copies") and not a claim.
Judge only that statement and where it stands. Do not fail the answer for what it goes on to include, such as page checks or markup notes.
