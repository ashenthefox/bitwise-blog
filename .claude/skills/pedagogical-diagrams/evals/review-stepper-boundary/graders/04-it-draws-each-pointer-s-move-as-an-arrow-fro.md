PASS if the answer says to draw a pointer's move in the figure itself, as an arrow or line from the pointer's previous position to its new one. A faint copy ("ghost") of the old position counts when it comes with such an arrow.
FAIL if the figure only marks what changed (a highlight, an outline, a flash, dimming the rest, a ghost with no arrow), or if the arrow is offered as optional.
An arrow that is drawn only for the wrap-around from the last slot to the first does not count.
