PASS if the design or prose names at least one thing this figure will show that a reader could take for a bug or for a property of Bloom filters in general, and says what it is. For example: a word that lights only 1 or 2 bits because hashes coincided; runs differing because the hashes look random; a 32-bit array filling far faster than a real filter would.
FAIL if no such artefact is named.
